# Компоненты SurPort

Документ для агентов и людей: что есть в проекте, как это работает и как добавлять новое.
Обновляй этот файл при добавлении каждого компонента.

## О проекте

SurPort — сайт-визуал ИИ-агента для сбора данных. Пользователь подключает свой ключ
провайдера, выбирает модель (`Sur 1`, `Sur Docs`, `Sur Brief`) и описывает задачу.
Агент сам строит промт-опросник под роль (юрист, студент, руководитель, сотрудник),
ведёт по шагам и отдаёт результат в нужном формате. Сайт показывает этот сценарий
по секциям, навигация по ним — через `BranchedMenu`.

## Стек и правила

- React 19 + Vite 8, **JavaScript (JSX), без TypeScript**.
- **Без Tailwind** и без UI-библиотек. Стили — обычный CSS в `src/index.css` (классы вида `.hero`).
- Линтер — `oxlint` (`npm run lint`). Сборка — `npm run build`.
- Импорты компонентов — относительные (`./components/...`).
- Палитра, токены и правила контраста — в [`design.md`](./design.md). Новый цвет сначала появляется там, потом в коде.
- Ничего из `src/components/*.jsx` не удалять без замены: `COMPONENTS.md` должен совпадать с диском.

## Слои страницы

1. `.silk-background` — `position: fixed; top: 0; left: 0; width: 100%; height: 100lvh; z-index: 0; pointer-events: none`.
   Фон не скроллится вместе с контентом: canvas всегда размером с вьюпорт.
   `100lvh` — максимальная высота вьюпорта: мобильные браузеры прячут адресную строку при скролле,
   но этот слой размер не меняет, поэтому canvas не пересчитывается и узор не «растягивается».
2. `main.app` — обычный поток документа, скроллится поверх фона, `position: relative; z-index: 1`.

Не ставь фону отрицательный `z-index`. Если у `html` есть свой фон, `body` перестаёт отдавать его корню
и рисует заливку поверх отрицательного слоя — фон пропадает, остаётся «дырка». Слой `0` + контент `1`
работает одинаково во всех браузерах.
`overscroll-behavior-y: none` на `html`/`body` убирает резиновый overscroll, который отрывает fixed-слой
от нижней кромки.

## Silk

`src/components/Silk.jsx` — анимированный WebGL2-фон из React Bits (шёлк).
Оригинал был TypeScript + Tailwind, здесь переписан на JSX и инлайн-стили, чтобы не тянуть хвосты.

### Как работает

- Рисует на `<canvas>` через WebGL2 (фрагментные шейдеры, без библиотек).
- Два прохода:
  1. `FIELD` — грубая копия узора в текстуру 1/4 размера, из неё строятся mip-уровни для свечения (`glow`).
  2. `COMPOSITE` — финальный кадр: узор, рельеф от производных, блик (`sheen`), свечение (`bloom`), зерно (`noiseIntensity`).
- Анимация — `requestAnimationFrame`; время набегает только при `speed !== 0` и `paused === false`.
- `intro` — 2.2 с разглаживания узора при первом кадре.
- `mouseInteraction` — курсор смещает узор и источник света. Слушатели висят на `window`, поэтому
  контейнер с `pointer-events: none` взаимодействию не мешает.
- `clickRipple` — волны от клика (по умолчанию в проекте выключено).
- Если у пользователя `prefers-reduced-motion: reduce`, анимация и intro отключаются.
- `IntersectionObserver` останавливает цикл, когда канвас вне вьюпорта; `visibilitychange` — когда вкладка скрыта.
- DPR ограничен 2 (`dpr` можно передать вручную).
- `resize()` сравнивает размеры буфера и пропускает перерисовку, если они не изменились:
  `ResizeObserver` на мобильных срабатывает во время скролла, а дёргать canvas там нельзя.
- При размонтировании удаляются буферы, текстуры, программы; контекст теряется, если канвас уже не в DOM.
  Поэтому `StrictMode` в dev безопасен.
- Поддержка WebGL2 обязательна: без контекста компонент просто не рисует и не падает.
- В `settingsRef.current = {...}` намеренно пишутся пропсы во время рендера (паттерн апстрима), рядом стоит
  `// oxlint-disable-next-line react/refs`. Не «исправляй» это на `useEffect`: кадр читает настройки синхронно.

### Позиционирование

`Silk` занимает 100% родителя (`position: relative`). Размер берётся из `clientWidth/clientHeight`
через `ResizeObserver`, так что родитель обязан иметь реальные размеры.

## SilkBackground

`src/components/SilkBackground.jsx` — обёртка-слой для фона страницы.

- Фиксирует `Silk` на весь вьюпорт: не двигается при скролле.
- Задаёт палитру проекта (красный шёлк) и `clickRipple={false}`.
- Пропсы прокидываются дальше: `<SilkBackground speed={2} />` переопределит дефолты.
- `aria-hidden` на контейнере: декоративный фон не попадает в дерево доступности.

Использование в `App.jsx`:

```jsx
import SilkBackground from './components/SilkBackground'

<SilkBackground />
<main className="app">{/* секции */}</main>
```

## SpecularButton

`src/components/SpecularButton.jsx` — кнопка-«стекло» со световым бликом по краю (React Bits).
Оригинал TypeScript + Tailwind, здесь JSX + CSS-классы из `src/index.css`.

### Как работает

- Форма кнопки — обычный `<button>`; поверх него `<canvas>` с отступом 24px, чтобы свечение не обрезалось.
- WebGL2-шейдер рисует рамку скруглённого прямоугольника и «бегущий» блик: `uSpot` — позиция света
  по периметру (0..1), `uIntensity` — яркость, `uWindow` — ширина и затухание луча.
- Блик следует за курсором (`followMouse`) на расстоянии `proximity`; когда курсор далеко —
  свет возвращается в угол покоя и притухает до `idleIntensity`.
- `autoAnimate` пускает свет по кругу без курсора.
- `prefers-reduced-motion` отключает вращение, но не реакцию на наведение.
- Перерисовка только при движении или затухании; вне вьюпорта цикл останавливается.

## BranchedMenu

`src/components/BranchedMenu.jsx` — меню-дерево с линиями-ветками (React Bits).
Оригинал TypeScript + Tailwind + `@hugeicons/react`, здесь JSX + CSS из `src/index.css`.
Зависимости: `@hugeicons/react`, `@hugeicons/core-free-icons`.

### Где используется

`src/sections/Explore.jsx`, секция «Карта проекта» (`id="overview"`). Пункт меню
прокручивает страницу к секции с тем же `id`: `document.getElementById(value).scrollIntoView()`.
Пункты описаны в `src/data/site.js` → `navSections`; текст раздела, иконка и `value`
совпадают с `id` секции.

### Как работает

- Два уровня: секция (сворачивается) и дочерний пункт (выбирается).
- Ветки — SVG-пути: вертикальная стойка, дуги к каждому пункту и «дотягивающаяся» линия
  активного пункта (`stroke-dasharray` / `stroke-dashoffset`).
- Активная секция подсвечивается маркером слева; позиция маркера считается из `offsetTop`
  заголовка и пересчитывается `ResizeObserver`.
- Сворачивание — `grid-template-rows: 0fr → 1fr`, без измерения высоты вручную.
- `prefers-reduced-motion` убирает переходы.

### Пропсы

| Проп | По умолчанию | Что делает |

| `items` | демо-набор | Секции `{ label, children: [{ value, label, icon }] }`. Лист без `children` — пункт верхнего уровня. |
| `defaultOpen` | `0` | Номер секции или массив номеров, открытых сразу. `-1` — все закрыты. |
| `defaultActive` | `''` | `value` активного пункта. Пусто — первый пункт открытой секции. |
| `onSelect` | — | `(value, item)` при выборе пункта. |
| `onToggle` | — | `(index, open)` при сворачивании секции. |
| `color` | `#f5f5f5` | Цвет текста. |
| `accentColor` | `#f5f5f5` | Активный пункт, маркер, активная линия. |
| `lineColor` | `#3f3f46` | Стойка и ветки. |
| `width` | `240` | Максимальная ширина меню, px (сжимается по контенту). |

## Добавление новой секции

1. Создай `src/sections/Name.jsx` (имя = смысл секции) и обёртку
   `<section className="section" id="anchor">` + `<div className="container">`.
2. Тексты складывай в `src/data/site.js`, а не в разметку: другие агенты ищут контент там.
3. Стили — в `src/index.css`, классы по BEM-подобной схеме (`.hero`, `.hero__title`).
4. Подключи в `App.jsx` внутри `<main className="app">`.
5. Если секция должна быть в «Карте проекта», добавь пункт в `navSections` с тем же `value`/`id`.
6. Допиши секцию в этот файл: назначение, пропсы, зависимости.
